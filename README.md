# 🏥 MediMonitor

A smart healthcare web application that provides basic medical guidance, pill identification, and emergency assistance.


Smart healthcare web app for:
- 💊 Pill identification  
- 🧑‍⚕️ Symptom-based suggestions  
- 🚑 Emergency support  

---

## 🚀 Features

### 🧑‍⚕️ Doctor Consultation
- Symptom → medicine suggestion  
- Age-based dosage (child/adult)  
- Do's & Don'ts  
- Home remedies  
- Patient ID generation  
- PDF prescription download  

---

### 💊 Pill Identifier
- Search by name / symptoms / color / shape  
- Live suggestions  
- Usage, dosage, warnings  
- PDF download  

---

### 🚑 Emergency
- 📞 Call: 108  
- 🏥 Find nearest hospital  
- ⚠ First aid (overdose, allergy)  

---

## 🛠️ Tech Stack
- HTML  
- CSS (Bootstrap)  
- JavaScript  
- jsPDF  
- LocalStorage
